# Task Management API

A production-ready Task Management REST API built with **Spring Boot 3**, **Spring Data JPA**, and **PostgreSQL**.

## Tech Stack
- **Language**: Java 21
- **Framework**: Spring Boot 3.4.3
- **Database**: PostgreSQL (Production/Dev), H2 (In-memory testing)
- **Data Access**: Spring Data JPA / Hibernate ORM
- **Testing**: JUnit 5, AssertJ, Spring Boot Test (`@DataJpaTest`, `@SpringBootTest`)
